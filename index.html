What we build

DynaMesh Studio is developing a proprietary procedural generation pipeline built with Python and Luau. It automates the creation of large-scale 3D province meshes for virtual environments and handles complex geometric configurations across regions.

Dynamic node scaling

Our architecture includes a dynamic city scaling system that calculates spatial representation from population parameters in real time.

  • Nodes with populations under 1,000,000 render as highly optimized cylinders.
  • Larger "mega-nodes" automatically transform into more complex square geometries.
  • The goal is to balance render cost with visual fidelity.

Roadmap

This is our plan. Items move to "done" only when they work.

Now — foundations

  • Project website and public repository (live).
  • Define the input format: region and population parameters per node.
  • First Python generator that builds a simple province mesh and exports it.
  • Implement the node scaling rule: cylinders under 1,000,000 population, square geometries above.
  • Automated checks for mesh output, and a first demo image.

Next — integration

  • Luau integration to bring generated meshes into the target environment.
  • Performance budgeting: part counts, level of detail, and render cost per node.
  • Batch generation across many provinces from a single data file.
  • Better validation to catch bad geometry automatically.

Later — scale

  • Generate configurations for many regions worldwide.
  • Real-time updates when population parameters change.
  • Simple tooling or interface to configure and preview a map.
  • Public demo and full documentation.
